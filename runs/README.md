# runs

Output of test and pipeline runs (screenshots, evidence, reports, context and intent files) goes here. The owner's rules (2026-11-16, corrected the same day):

1. This folder is ignored by git. Run output is never committed.
2. Run output is read only to find what went wrong. Each finding is written into docs/TROUBLESHOOTING.md and worked with the detective method.
3. Once a finding is solved, its run output is deleted (the owner authorized this).
4. Agents never go back into old runs to pull information out and use it as a source.

Each run writes a new, dated folder; nothing here is overwritten.
